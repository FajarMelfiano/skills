# SEO Basics

## Purpose

Membuat halaman web ramah mesin pencari dengan fondasi SEO yang benar:
meta tags lengkap, struktur heading logis, HTML semantik, dan performa
yang cepat. Fokus pada hal yang berdampak besar dengan usaha kecil.

## Workflow

1. **Riset kata kunci.** Tentukan 1 kata kunci utama + 3–5 turunan per
   halaman. Kata kunci utama harus muncul di title, H1, dan paragraf awal.
2. **Tulis meta tags.** Buat: `<title>` (±60 karakter, kata kunci di depan),
   meta description (±155 karakter, mengajak klik), Open Graph tags
   untuk share sosmed, dan canonical URL.
3. **Struktur heading.** Satu `<h1>` per halaman, `<h2>` untuk section
   utama, `<h3>` untuk sub-bagian. Jangan loncat level (h1 → h3).
4. **Semantic HTML.** Gunakan tag bermakna: `<article>`, `<nav>`,
   `<header>`, `<footer>`, `<figure>` + `<figcaption>`. Satu `<main>`
   per halaman.
5. **Optimasi konten & media.** Paragraf pembuka menjawab intent pencarian.
   Gambar: nama file deskriptif, alt text bermakna, ukuran dikompres,
   pakai `loading="lazy"` untuk gambar bawah.
6. **Cek performa & teknis.** Pastikan: mobile-friendly, HTTPS, waktu muat
   < 3 detik, tidak ada link rusak, dan sitemap + robots.txt tersedia.

## Output Contract

- Daftar kata kunci utama + turunan per halaman.
- Blok meta tags siap tempel (title, description, OG, canonical).
- Outline heading (H1/H2/H3) untuk halaman tersebut.
- Checklist teknis: performa, mobile, link, sitemap — status per item.

## Operating Rules

- Jangan stuffing kata kunci; tulis untuk manusia dulu, mesin kedua.
- Setiap halaman = satu topik = satu kata kunci utama. Tanpa kecuali.
- Alt text menjelaskan isi gambar, bukan "gambar1.jpg".
- URL pendek, lowercase, pakai strip: `/tips-seo-pemula`.
- Jangan janjikan ranking #1; SEO adalah probabilitas, bukan garansi.
